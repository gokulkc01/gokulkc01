## 🔧 Active Projects

**[VirtuNode](https://github.com/gokulkc01/virtunode-backend)** — Cloud-Based IoT Digital Twin Platform
> Test sensor logic without physical hardware. FastAPI + Docker SDK sandboxes + Redis pub/sub streaming to WebSocket clients in sub-second latency. Resolved async event-loop deadlock in multi-worker Uvicorn via executor-based container I/O.
>
> `FastAPI` `Redis` `Docker` `WebSockets` `React` `Uvicorn` `Python`

**SentryNet** — Trust-Aware Multi-Agent RL Drone Surveillance
> 3-agent cooperative MARL system in a PyBullet 3D airspace. EMA-based trust scoring under adversarial packet drops (Bernoulli + Gaussian spoofing). **>60% capture rate** at 30% comms loss — vs <40% baseline. Full MAPPO pipeline with WandB + ONNX export.
>
> `PyTorch` `PyBullet` `PettingZoo` `MAPPO` `WandB` `ONNX` `pytest`

**[FarmAssist](https://github.com/gokulkc01)** — Edge-Cloud Smart Agriculture Platform
> ESP32 + TinyML + LoRa + Raspberry Pi. **90%+ on-device classification**, **<50ms inference**, **35% water reduction**. Reduced cloud bandwidth by **70%** via edge-first architecture with quantized INT8 models (2.1MB → 180KB).
>
> `TF Lite` `ESP32` `LoRa` `React` `Node.js` `MongoDB`

**[File Integrity Monitor](https://github.com/gokulkc01)** — Behavioral Ransomware Detection
> SHA-256 hashing + entropy analysis + rate-of-change detection + directory traversal patterns. **96.3% accuracy** across 500+ simulated attack scenarios, **<500ms** detection latency, automated rollback.
>
> `Node.js` `Chokidar` `Socket.io` `SHA-256` `React`
